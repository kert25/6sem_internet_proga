XML-валидация (ЛР4–6) — PowerShell + .NET, без внешних парсеров:

## 6. Дизайн XML «Видеотека» (общий для ЛР4–6)

```xml
<?xml version="1.0" encoding="UTF-8"?>
<видеотека>
  <фильм id="ф1" жанр="фантастика">
    <название>Интерстеллар</название>
    <год>2014</год>                       <!-- XSD: xsd:integer -->
    <режиссёр>Кристофер Нолан</режиссёр>
    <актёр>Мэттью Макконахи</актёр>        <!-- 1..n, maxOccurs="unbounded" -->
    <актёр>Энн Хэтэуэй</актёр>
    <продолжительность>169</продолжительность>  <!-- XSD: xsd:positiveInteger, минуты -->
    <рейтинг>8.6</рейтинг>                 <!-- XSD: xsd:decimal -->
    <аннотация>…</аннотация>               <!-- опционально: DTD «?», XSD minOccurs="0" -->
  </фильм>
  <!-- всего 5–6 фильмов, у части аннотации нет; жанры: комедия|драма|боевик|фантастика|триллер -->
</видеотека>
```

Покрытие требований:
- DTD (ЛР5, внешняя `videoteka.dtd`): `<!ELEMENT видеотека (фильм+)>`; `<!ELEMENT фильм (название, год, режиссёр, актёр+, продолжительность, рейтинг, аннотация?)>`; `<!ATTLIST фильм id ID #REQUIRED жанр (комедия|драма|боевик|фантастика|триллер) #REQUIRED>`; enum в DTD только для атрибутов — поэтому «жанр» атрибут.
- XSD (ЛР6, `videotека.xsd` — латиницей имени файла: `videoteka.xsd`): типы `xsd:integer` / `xsd:positiveInteger` / `xsd:decimal`; атрибут `жанр` — `xsd:restriction`+`enumeration`; `id` — `xsd:ID` или `xsd:string` с `use="required"`; `аннотация` — `minOccurs="0"`; `актёр` — `maxOccurs="unbounded"`.
- Ошибки для демонстрации непрохождения валидации (ЛР5, повторить в ЛР6): значение жанра вне перечня; дубликат `id`; отсутствие обязательного элемента (`название`); посторонний элемент.
