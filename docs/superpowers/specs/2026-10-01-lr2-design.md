# ЛР2: функции и обработка событий JavaScript — дизайн

## Контекст

Официальная лабораторная работа №10 по дисциплине «Интернет-программирование».
Тема: «Функция и обработка события на JavaScript». Вариант 9.

Методичка назначает для варианта индивидуальные задания 9, 2, 12 и 13.

## Результат

Рабочий каталог `ЛР2/` содержит четыре независимые HTML-страницы в UTF-8,
скриншоты результатов, отчёт и конспект для защиты.

| Файл | Задание | Требуемое поведение |
|---|---:|---|
| `Ex9.html` | 9 | Показывает диалоговое окно, затем после нажатия OK выводит в странице `Hello, world!`. |
| `Ex2.html` | 2 | Принимает основание и высоту треугольника, рассчитывает площадь по щелчку кнопки и отображает треугольник. |
| `Ex12.html` | 12 | Обрабатывает анкету: переводит фамилию в верхний регистр, заменяет возраст меньше 18 на 0, выводит содержимое полей по `Complete` и сбрасывает форму по `Reset`. |
| `Ex13.html` | 13 | Проводит тест по JavaScript: пять вопросов, три ответа на каждый, первый ответ правильный; показывает результат пользователю. |

## Реализация

Каждая страница независима и содержит функции JavaScript для обработчиков
событий. Разметка использует семантические формы и доступные подписи полей.
Комментарии поясняют нетривиальные участки кода.

`Ex2.html` дополнительно проверяет, что основание и высота — положительные
числа. После корректного ввода выводятся площадь и SVG-изображение
треугольника с сохранением пропорций.

`Ex13.html` использует радиокнопки, а подсчёт результата производится только
после отправки формы. Итоговая оценка показывается без перезагрузки страницы.

## Отчёт и проверка

В `content.json` будут: цель, точные формулировки четырёх заданий, листинги
всех файлов, скриншоты и вывод. `content_text.json` опишет демонстрацию и
подготовит ответы на вероятные вопросы по функциям, событиям, формам и DOM.

Проверка включает запуск страниц через CDP, проверку интерактивных сценариев,
создание DOCX и PDF и проверку структуры отчёта и текста PDF. Состояние и
артефакты фиксируются в `_lab_state.json`.
