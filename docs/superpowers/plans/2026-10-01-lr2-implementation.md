# ЛР2: функции и обработка событий JavaScript Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Выполнить вариант 9 ЛР10: четыре интерактивные HTML-страницы, отчёт, PDF и конспект для защиты.

**Architecture:** Каждое индивидуальное задание реализуется отдельной автономной HTML-страницей в `ЛР2/`. Функции JavaScript обрабатывают события формы и обновляют DOM без перезагрузки страницы; результаты проверяются запуском в Edge через CDP. Отчёт собирается локальным `make_docx.py` из JSON-описаний и проверяется по DOCX/PDF.

**Tech Stack:** HTML5, CSS3, vanilla JavaScript, SVG, Edge/CDP, Python (`make_docx.py`), Microsoft Word COM или LibreOffice.

**Spec:** `docs/superpowers/specs/2026-10-01-lr2-design.md`

## Global Constraints

- Реализовать строго задания 9, 2, 12 и 13, назначенные варианту 9 в методичке ЛР10.
- Все HTML-файлы сохранять в UTF-8 и сопровождать код поясняющими комментариями.
- Не добавлять внешние зависимости.
- Скриншоты сохранять в `ЛР2/screenshots/` в формате PNG.
- Итоговые артефакты: `ЛР2/Отчет_ЛР2.docx`, `ЛР2/Отчет_ЛР2.pdf`, `ЛР2/text.docx`.

## Review Focus

- Пустые, нечисловые, нулевые и отрицательные размеры треугольника должны вывести понятное сообщение вместо расчёта или SVG.
- Фамилия с кириллицей и смешанным регистром должна полностью стать прописной до показа результата.
- Возраст 17 и меньше должен стать `0`, а возраст 18 — остаться без изменения.
- Сброс анкеты должен очистить как значения формы, так и ранее показанное сообщение о результате.
- Неотмеченные варианты теста должны быть учтены как неправильные, а полный правильный ответ должен дать 5 из 5.

- [ ] **Step 5: Проверить ошибочные размеры треугольника**

По очереди передать пустое значение, `текст`, `0` и `-3`, затем вызвать `calculateTriangle()`.

Expected: для каждого случая показано сообщение об ошибке и SVG отсутствует.

### Task 2: Реализовать обработку анкеты из задания 12

**Files:**
- Create: `ЛР2/Ex12.html`
- Create: `ЛР2/screenshots/ex12.png`
- Create: `ЛР2/screenshots/ex12_reset.png`

**Interfaces:**
- Consumes: требования методички задания 12.
- Produces: функции `normalizeSurname() -> void`, `normalizeAge() -> void`, `completeForm() -> void`, `resetForm() -> void`.

- [ ] **Step 1: Создать форму анкеты и функцию `normalizeSurname()`**

Добавить текстовое поле фамилии `surname`. На событие изменения вызывать `normalizeSurname()`, которое заменяет значение на `surname.value.toUpperCase()`.

- [ ] **Step 2: Проверить обработку фамилии**

Через CDP задать значение `Иванов`, инициировать `change` и проверить `#surname.value`.

Expected: поле содержит `ИВАНОВ`.

- [ ] **Step 3: Добавить `normalizeAge()` и обработчик изменения поля возраста**

Добавить поле `age`. Функция должна установить `age.value = "0"`, если числовое значение меньше 18; возраст 18 и больше не изменять.

- [ ] **Step 4: Проверить границу возраста**

Через CDP вызвать `normalizeAge()` со значениями 17 и 18.

Expected: результат соответственно `0` и `18`.

- [ ] **Step 5: Добавить `completeForm()` и `resetForm()`**

Кнопка `Complete` вызывает `completeForm()`: нормализует фамилию и возраст, выводит значения всех полей в `alert()` и дублирует итог в доступном элементе `#summary`. Кнопка `Reset` вызывает `resetForm()`: сбрасывает форму и очищает `#summary`.

- [ ] **Step 6: Проверить итог и сброс анкеты**

Заполнить форму через CDP, выполнить `completeForm()`, принять диалог и сохранить `ЛР2/screenshots/ex12.png`. Затем выполнить `resetForm()` и сохранить `ЛР2/screenshots/ex12_reset.png`.

Expected: итог содержит нормализованные значения; после сброса все поля исходные и `#summary` пуст.

### Task 3: Реализовать тест JavaScript из задания 13

**Files:**
- Create: `ЛР2/Ex13.html`
- Create: `ЛР2/screenshots/ex13.png`
- Create: `ЛР2/screenshots/ex13_partial.png`

**Interfaces:**
- Consumes: требование: пять вопросов, по три ответа, первый ответ правильный.
- Produces: функция `evaluateTest() -> void`, элемент результата `#test-result`.

- [ ] **Step 1: Создать тестовую форму из пяти вопросов**

Для каждого вопроса создать группу из трёх радиокнопок с уникальным `name`. Первую кнопку пометить `data-correct="true"`; вопросы должны покрывать функции, события, формы и DOM JavaScript.

- [ ] **Step 2: Реализовать `evaluateTest()`**

На отправку формы вызвать `event.preventDefault()`, подсчитать отмеченные элементы с `data-correct="true"` и вывести `Правильных ответов: X из 5` в `#test-result`. Неотмеченная группа считается неправильной.

- [ ] **Step 3: Проверить полностью правильный тест**

Через CDP выбрать первые ответы всех пяти вопросов, отправить форму и проверить DOM.

Expected: `#test-result` содержит `5 из 5`; сохранить `ЛР2/screenshots/ex13.png`.

- [ ] **Step 4: Проверить неполный тест**

Выбрать один правильный ответ, оставить четыре вопроса без ответа и отправить форму.

Expected: `#test-result` содержит `1 из 5`; сохранить `ЛР2/screenshots/ex13_partial.png`.
